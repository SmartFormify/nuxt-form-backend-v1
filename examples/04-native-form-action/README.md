# Native HTML Form Action in Nuxt

Use this when the endpoint should own browser navigation and you do not need in-page async state:

```html
<form action="https://api.smartformify.com/fe/YOUR_ENDPOINT_KEY" method="POST">
```

The endpoint redirects or displays its configured thank-you content. See [Nuxt form submission options](../../docs/nuxt-form-submit.md).
