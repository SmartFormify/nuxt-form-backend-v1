# Nuxt Forms v1

A collection of reusable **Nuxt JS form examples** designed to submit form data directly to **SmartFormify**.

This project is intended for a blog and example repository where developers can copy a Nuxt Vue form, connect it to a SmartFormify endpoint, and start receiving form submissions without building a custom form-processing backend for each example.

## Why Use SmartFormify?

SmartFormify lets your Nuxt website forms submit data to a hosted form endpoint instead of requiring you to build and maintain your own form-processing backend for the form.

With this approach:

- Keep your Nuxt project focused on the frontend form UI.
- Use your existing Nuxt Vue forms.
- Submit forms directly to a SmartFormify endpoint.
- Avoid creating a separate custom form-processing endpoint for every form.
- Reuse the same endpoint-based integration pattern across different forms.
- Manage submissions and post-submission behavior through SmartFormify.
- Keep form examples lightweight and easy to reuse.

The basic integration is:

```text
Nuxt Vue Form
        ↓
SmartFormify Endpoint
        ↓
Submission Processing
```

## Benefits of Using SmartFormify

- **No custom form backend required:** Submit directly to a hosted SmartFormify endpoint.
- **Keep your existing design:** Your Vue markup, CSS, fields, labels, and responsive UI remain under your control.
- **Reusable integration:** The same endpoint pattern can be used across many Nuxt forms.
- **Submission management:** Manage submissions and configured post-submission behavior through SmartFormify.
- **Simple deployment:** Keep the examples focused on Nuxt Vue and frontend form code.

## How to Sign Up for SmartFormify

1. Open the SmartFormify website.
2. Create a SmartFormify account.
3. Sign in to the SmartFormify dashboard.
4. Create a new form/endpoint.
5. Configure the endpoint as required.
6. Copy the endpoint URL.
7. Add the endpoint URL to your Nuxt Vue form.
8. Submit a test form.

> Dashboard labels and signup steps may change. Follow the current SmartFormify dashboard instructions when creating your account or endpoint.

## How to Create a SmartFormify Endpoint URL

After signing in to SmartFormify:

1. Open your SmartFormify dashboard.
2. Create a new form or endpoint.
3. Give the form a meaningful name.
4. Configure any required endpoint or security settings.
5. Copy the unique endpoint URL generated by SmartFormify.

For example, the endpoint will conceptually look like:

```text
https://api.smartformify.com/v1/f/your-unique-id
```

Your actual endpoint URL will be different.

Use the endpoint URL as the Nuxt form's `action`:

```blade
<form
    action="YOUR_SMARTFORMIFY_ENDPOINT_URL"
    method="POST"
>
```

Replace `YOUR_SMARTFORMIFY_ENDPOINT_URL` with the actual endpoint generated by SmartFormify.

# How to Connect a Nuxt Vue Form to SmartFormify

Nuxt forms are usually stored using the `.vue` extension.

For example:

```text
pages/
└── form-name.vue
assets/
└── style.css
nuxt.config.ts
package.json
```

A basic Vue form can connect to SmartFormify using the endpoint URL in the `action` attribute.

## Before

```blade
<form>
```

## After

```blade
<form
    action="YOUR_SMARTFORMIFY_ENDPOINT_URL"
    method="POST"
>
```

The important part is the `action` attribute. It tells the browser where the form submission should be sent.

## Complete Nuxt Vue Example

```blade
<form
    action="YOUR_SMARTFORMIFY_ENDPOINT_URL"
    method="POST"
>
    <div class="form-group">
        <label for="name">Name</label>

        <input
            type="text"
            id="name"
            name="name"
            required
        >
    </div>

    <div class="form-group">
        <label for="email">Email</label>

        <input
            type="email"
            id="email"
            name="email"
            required
        >
    </div>

    <div class="form-group">
        <label for="message">Message</label>

        <textarea
            id="message"
            name="message"
            required
        ></textarea>
    </div>

    <input
        type="hidden"
        name="notes_hqse"
        value=""
    >

    <button type="submit">
        Send Message
    </button>
</form>
```

Replace `YOUR_SMARTFORMIFY_ENDPOINT_URL` with your actual SmartFormify endpoint.

## How to Add the Endpoint to an Existing `.vue` File

If you already have a Nuxt form, you usually don't need to rebuild it.

Before:

```blade
<form>
    <!-- existing form fields -->
</form>
```

After:

```blade
<form
    action="YOUR_SMARTFORMIFY_ENDPOINT_URL"
    method="POST"
>
    <!-- existing form fields -->
</form>
```

Keep the existing design and fields. The main connection is the SmartFormify endpoint in the `action` attribute.

# Important: Use Meaningful `name` Attributes

Every field that should be submitted should have an appropriate `name` attribute.

For example:

```blade
<input
    type="text"
    name="first_name"
>
```

```blade
<input
    type="email"
    name="email"
>
```

```blade
<textarea
    name="message"
></textarea>
```

A form can contain fields such as:

```blade
<input name="first_name">
<input name="last_name">
<input name="email">
<input name="company">
<input name="phone">
<textarea name="message"></textarea>
```

The `name` attribute identifies the submitted field value.

# SmartFormify Hidden Field

Keep this field in every form:

```blade
<input
    type="hidden"
    name="notes_hqse"
    value=""
>
```

Important:

- Keep the name exactly `notes_hqse`.
- Keep the value empty.
- Do not remove the field.
- Do not add normal validation to this field.

# After Submission

SmartFormify can be configured for post-submission behavior.

Depending on the configured workflow, SmartFormify can provide a response such as a redirect URL or thank-you content.

Configure the desired after-submission behavior in SmartFormify rather than adding a separate form-processing backend to each Nuxt example.

The basic workflow is:

```text
Nuxt Vue Form
        ↓
SmartFormify Endpoint
        ↓
Submission Processing
        ↓
Redirect / Thank-You Response
```

# Domain and Security Settings

If your SmartFormify endpoint uses domain allowlisting or other security controls, configure the domain where the Nuxt form is hosted.

For local development, allow the exact origin used by your Nuxt development environment when required.

For example:

```text
http://localhost:8000
```

For production, configure your deployed website domain as required by the endpoint.

# Using the Form Examples in Nuxt

Each form example is designed to be copied into a Nuxt Vue project.

A typical Nuxt structure can look like:

```text
resources/
└── views/
    └── forms/
        ├── contact_form.vue
        ├── newsletter_signup.vue
        ├── booking_form.vue
        └── ...
```

To use an example:

1. Copy the desired `.vue` file into your Nuxt project's `resources/views` directory.
2. Keep or copy the related CSS file.
3. Open the Vue page/component.
4. Replace `YOUR_SMARTFORMIFY_ENDPOINT_URL` with your actual endpoint.
5. Check the form fields and `name` attributes.
6. Keep the `notes_hqse` hidden field.
7. Configure the endpoint in SmartFormify.
8. Run your Nuxt project.
9. Open the form in the browser.
10. Submit a test response.
11. Verify the submission in SmartFormify.

# Forms With JavaScript

Some Nuxt forms may include JavaScript for custom validation, loading states, or UI behavior.

If JavaScript intercepts submission using:

```javascript
event.preventDefault();
```

make sure it still sends the form data to the SmartFormify endpoint.

If custom JavaScript submission is not required, a standard form submission is the simplest approach:

```blade
<form
    action="YOUR_SMARTFORMIFY_ENDPOINT_URL"
    method="POST"
>
```

# File Upload Forms

The **Contact Form with File Upload** and other upload-enabled examples are intended for file submissions.

Make sure the SmartFormify endpoint is configured for the upload workflow and that the Vue form uses the encoding required by the endpoint.

For example:

```blade
<form
    action="YOUR_SMARTFORMIFY_ENDPOINT_URL"
    method="POST"
    enctype="multipart/form-data"
>
```

Follow the requirements of the specific SmartFormify upload workflow when configuring the endpoint and form.

# Project Structure

Each Nuxt form example follows a simple structure:

```text
form-name/
├── README.md
├── pages/
│   └── form-name.vue
├── assets/
│   └── style.css
├── nuxt.config.ts
└── package.json
```

The `.vue` file contains the Nuxt/Vue form.

`style.css` contains the styling.

`nuxt.config.ts` contains Nuxt configuration such as global CSS and runtime configuration.

The individual `README.md` explains the form and its SmartFormify setup.

- Keep their existing form design.
- Connect forms to SmartFormify.
- Avoid creating a separate custom form-processing endpoint for each example.
- Test and reuse different form patterns.
- Manage form submissions through SmartFormify.

The core integration is:

```text
Nuxt Vue Form
        ↓
SmartFormify Endpoint
        ↓
Submission Processing
```
