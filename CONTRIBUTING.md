# Contributing

Contributions should add a genuinely useful Nuxt form pattern, improve Nuxt 4 or TypeScript correctness, accessibility, validation, Nuxt UI usage, or documentation. Run `pnpm check-links` and `pnpm verify` before opening a pull request.

Do not add duplicate forms, generated SEO pages, copied tutorials, unrelated frameworks, promotional backlinks, endpoint keys, or unsupported SmartFormify claims.
